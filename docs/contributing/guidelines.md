# Contributing Guidelines

## Overview
Thank you for your interest in contributing to the Marriott Hotels platform! This document outlines the process for contributing code, documentation, and ideas.

## How to Contribute
- Fork the repository and create your branch from `main`.
- If you've fixed a bug or added a feature, ensure tests are included.
- If you have questions, open an issue or start a discussion.

## Code of Conduct
- Be respectful and inclusive.
- No harassment, discrimination, or inappropriate behavior.
- See [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) for details.

## Reporting Issues
- Use the GitHub Issues tab to report bugs or request features.
- Provide as much detail as possible, including steps to reproduce.
- Label your issue appropriately (bug, enhancement, question, etc.).

## Submitting Pull Requests
- Ensure your branch is up to date with `main`.
- Open a pull request with a clear description of your changes.
- Reference related issues in your PR description.
- Follow the PR template if available.

## Code Review Process
- All PRs require at least one approval before merging.
- Address all review comments and suggestions.
- Be open to feedback and iterate as needed.

## Style Guide
- Follow the [Code Standards](code-standards.md) and [Documentation Standards](documentation-standards.md).
- Use consistent formatting and naming conventions.
- Write clear, concise commit messages.

## Community
- Join discussions in GitHub Discussions or Slack (if available).
- Attend community meetings and contribute to documentation.
- Help review and triage issues and PRs.
